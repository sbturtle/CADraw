# 결정 0004: 치수 확인 행이 geometry 선택을 제어

## 상태

채택

## 맥락

CAD를 모르는 사용자는 `line_raw_001` 같은 내부 ID만 보고 사진 속 어느 선의
치수인지 알 수 없습니다. 확인할 값을 입력하기 전에 원본 선과 정규화 preview의
대응 관계를 눈으로 확인해야 합니다.

## 결정

치수 확인 테이블은 단일 행 선택을 지원하고, 선택 상태를 다음 두 표면에
동시에 반영합니다.

- 행 label은 `선 · 방향 · 로컬 길이` 형식의 작업장 용어를 사용합니다.
- CAD preview에서는 대응 `EntityId`를 `accent-coral`로 굵게 표시합니다.
- 원본 사진에서는 대응 `LineEntity.raw_start/raw_end`를 같은 색으로 덧그립니다.
- 값 편집과 재계산 뒤에도 선택한 `DimensionId`를 유지합니다.
- geometry 계산이나 실제 치수 추론은 선택 동작에서 수행하지 않습니다.

## 이유

선택은 인식 결과를 제작 치수로 확정하는 행위가 아니라, 사람이 대상 geometry를
확인하기 위한 시각적 연결입니다. 따라서 선택 상태는 immutable analysis를
바꾸지 않고, preview와 source overlay에만 적용합니다. 실제 값은 기존과 같이
사용자가 직접 입력하고 확정해야 합니다.

## 한계

현재 수동 확인 행은 검출된 선만 만들므로 원, 호, polyline 전용 선택 행은
다음 geometry 단계에서 추가합니다. 원본 overlay도 현재는 선 entity만 그립니다.
