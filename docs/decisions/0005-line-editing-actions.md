# 결정 0005: 선 교정은 source-space 편집 명령으로 제공

## 상태

채택

## 맥락

선 검출은 한 획을 여러 조각으로 나누거나 글자·잡음을 구조선으로 오인할 수
있습니다. 사용자가 다시 사진을 분석할 때까지 기다리면 같은 오류가 반복되고,
preview만 직접 고치면 원본 좌표와 DXF 결과가 달라집니다.

## 결정

확인 테이블에 세 가지 선 교정 액션을 둡니다.

- `선 병합`: 여러 행을 선택해 near-collinear 선 조각을 canonical `LineEntity`
  하나로 합칩니다.
- `선 삭제`: 선택 선과 그 선만 가리키는 미확인 치수 행을 제거합니다.
- `선 다시 그리기`: 원본 이미지에서 두 점을 드래그합니다. 선 하나를 선택한
  경우 기존 ID를 교체하고, 여러 선을 선택한 경우 선택된 모든 선을 지우고 그
  자리를 방금 그린 한 선으로 대체하며(선택 ID 중 최솟값을 그대로 사용), 선택하지
  않은 경우 새 `manual_line_NNN`을 추가합니다. 여러 선을 하나로 합치는 데는
  `선 병합`처럼 near-collinear 판정이 필요 없으므로, 검출이 한 획을 서로 어긋나게
  쪼갠 경우에도 다시 그리기로 즉시 하나의 선으로 되돌릴 수 있습니다.

모든 액션은 `DrawingAnalysis`를 직접 수정하지 않고 새 immutable analysis를
만들며, 이후 기존 calculator → preview → export 경계를 그대로 사용합니다.
병합·삭제·다중 선택 다시 그리기 대상에 확정 치수가 있으면 데이터 손실을 막기
위해 거부합니다.

## 이유

source-space의 raw endpoint를 단일 진실로 유지하면 원본 highlight, 정규화
preview, DXF export가 같은 geometry identity를 공유합니다. 별도 화면 위에
임의의 선을 그리는 방식은 분석 모델과 표시 결과가 어긋날 위험이 큽니다.

## 한계

현재 액션은 `LineEntity`만 대상으로 하며 undo/redo와 다중 단계 command history는
아직 없습니다. 원·호·polyline을 교정하는 전용 도구는 후속 geometry 편집 단계에서
추가합니다.
