# 레퍼런스 정답 대비 추출 정확도

ADR-0019의 측정 기록입니다. 날짜: 2026-10-29.

## 정답

`sample-geometry-ground-truth.json`은 스캔(`sample/pure_background/1-7.png`)
픽셀 좌표로 따라 그린 정답입니다. 요소 종류는 `outline`(부품 외곽선, 열린
프로파일은 `closed: false`), `hole`(중심·반지름), `slot`, `cutout`, `ignore`
(판단이 갈리는 표시, 점수에서 제외)입니다. 레퍼런스 DXF가 단순화한 부분은
스캔에 실제로 그려진 형상을 따랐고, 샘플마다 `notes`에 그 차이를 적었습니다.

## 지표

`scripts/run_reference_benchmark.py`:

- 경계 정밀도·재현율·F1: 허용 거리 `max(6px, 대각선의 0.6%)`.
- 외곽선: 추출된 닫힌 도형과 IoU 0.8 이상(열린 프로파일은 길이의 90% 이상
  덮임).
- 구멍: 중심이 `max(4px, 반지름/2)` 안이고 반지름 비가 0.6~1.6.
- 슬롯·컷아웃: IoU 0.5 이상, 일대일.
- 오검출: 어느 정답과도 맞지 않고 `ignore` 밖에 있는 닫힌 도형.

## 사진 결과 (근사)

같은 정답을 SIFT 호모그래피로 원본 사진(`sample/1-7.jpg`)에 옮겨
`--ground-truth`로 잰 값입니다. 사진의 종이는 휘어 있어 호모그래피가 정확하지
않습니다. 정렬을 눈으로 확인했을 때 1·2·5번은 잘 맞고, 3·6번은 수~수십 px
어긋나며, 4번(인라이어 7개)과 7번(16개)은 믿을 수 없습니다. 추세를 보는
용도로만 씁니다.

| 지표 | 이전 | 이후 |
| --- | --- | --- |
| 경계 F1 평균 | 0.26 | 0.41 |
| 외곽선 | 3/18 | 6/18 |
| 구멍 | 0/26 | 3/26 |
| 슬롯·컷아웃 | 6/19 | 12/19 |
| 오검출 | 128 | 158 |
| 장당 시간(초) | 2.9~8.6 | 4.0~11.2 |

5번 사진은 외곽선 2/2, 슬롯 12/12가 되었습니다. 오검출 증가는 대부분 4번(정답
정렬 실패로 모든 도형이 오검출로 세어짐)과 2번(옆 서류의 인쇄 칸)입니다.

## 재현

```powershell
uv run python scripts/run_reference_benchmark.py
uv run python scripts/run_reference_benchmark.py --ground-truth <사진 정답 JSON>
```

결과는 `artifacts/reference_benchmark.json`에 저장됩니다.
