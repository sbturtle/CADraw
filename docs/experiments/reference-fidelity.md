# 레퍼런스 정답 대비 추출 정확도

ADR-0019~0021의 측정 기록입니다. 날짜: 2026-10-29.

## 정답

`sample-geometry-ground-truth.json`은 스캔(`sample/pure_background/1-7.png`)
픽셀 좌표로 따라 그린 정답입니다. 요소 종류는 `outline`(부품 외곽선, 열린
프로파일은 `closed: false`), `hole`(중심·반지름), `slot`, `cutout`, `ignore`
(판단이 갈리는 표시, 점수에서 제외)입니다. 레퍼런스 DXF가 단순화한 부분은
스캔에 실제로 그려진 형상을 따랐고, 샘플마다 `notes`에 그 차이를 적었습니다.

## 지표

`scripts/run_reference_benchmark.py`:

- 경계 정밀도·재현율·F1: 허용 거리 `max(6px, 대각선의 0.6%)`. `ignore` 영역
  안의 추출 경계 픽셀과 정답 경계 픽셀은 정밀도와 재현율의 집계에서 모두
  뺍니다. 거리 계산에는 그대로 들어가므로, `ignore` 밖의 추출 경계가 그
  안의 정답 경계 가까이에 있으면 맞은 것으로 셉니다.
- 외곽선: 추출된 닫힌 도형과 IoU 0.8 이상(열린 프로파일은 길이의 90% 이상
  덮임).
- 구멍: 중심이 `max(4px, 반지름/2)` 안이고 반지름 비가 0.6~1.6, 일대일.
- 슬롯·컷아웃: IoU 0.5 이상, 일대일.
- 오검출: 어느 정답과도 맞지 않고 `ignore` 밖에 있는 닫힌 도형. 구멍과
  일대일로 배정된 원만 오검출에서 빠집니다.

처음 공개한 채점은 `ignore` 안의 검출을 일부 세고 구멍 근처의 원을 모두
오검출에서 뺐습니다. 아래 수치는 모두 고친 채점으로 다시 잰 값입니다.

## 채택하지 않은 시도

- **배치만으로 글자 줄 찾기.** OCR 없이 글자 크기 잉크가 글자 간격으로 늘어선
  것을 문자열로 보고 그 안의 고리를 지웠더니, 오검출은 하나도 줄지 않고 구멍
  19→13, 슬롯 18→15로 떨어졌습니다.
- **원 둘레 근거로 원 복원.** Hough 원 후보 중 둘레의 75% 이상이 잉크인 것을
  원으로 받으면 5번 중앙 Ø200 원 하나를 맞히는 동안 다른 스캔에서 가짜 원이
  55개 생겼고, 원 바깥·안쪽이 비어 있어야 한다는 조건을 더하면 Ø200 원도
  탈락했습니다.
- **잉크 지지율로 선 거르기.** 정답 선과 아닌 선의 지지율 분포가 겹쳤습니다
  (7번의 흐린 진짜 변 0.30~0.34, 가짜 선 0.38~0.58).
- **곧은 변만 있는 다각형을 인쇄 칸으로 지우기.** 7번의 자로 그은 부품
  외곽선이 칸으로 판정되었습니다(ADR-0020).

## 재현

```powershell
uv run python scripts/run_reference_benchmark.py
uv run python scripts/run_reference_benchmark.py --ground-truth <사진 정답 JSON>
```

결과는 `artifacts/reference_benchmark.json`에 저장됩니다.
